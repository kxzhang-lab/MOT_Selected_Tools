# MOT Target Visualizer

## 项目简介
本项目用于**多目标跟踪（MOT）数据集**的辅助分析与可视化。它可以从标准的MOT标注文件中，筛选出用户指定的目标ID，提取其所有帧的边界框坐标，并将这些轨迹重新绘制到原始图像序列上，生成便于观察的MP4视频。

## 主要功能
- **目标筛选**：支持按一个或多个ID提取特定目标的轨迹。
- **坐标导出**：将目标在所有出现帧中的边界框坐标（x, y, w, h）导出为CSV或JSON文件。
- **视频生成**：将筛选出的目标轨迹以彩色边框叠加在原图上，并合成为视频。
- **灵活配置**：可自由指定视频的起始/结束帧、输出帧率、边框颜色和线宽。

## 适用场景
- 分析某几个特定目标（例如频繁遮挡或ID切换的对象）的跟踪表现。
- 生成论文或报告中的可视化示例片段。
- 辅助调试MOT算法，观察特定目标的行为。
